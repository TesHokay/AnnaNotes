# Ручная проверка на iPad и Apple Pencil

Автотесты в настольном браузере не заменяют проверку на устройстве. Проверяйте опубликованную по HTTPS сборку: в Safari и **отдельно** в установленном приложении (у него своё хранилище).

Устройство / iPadOS / модель Pencil / версия и commit (Настройки → «Для разработчиков»): ____________________

## 1. Офлайн-запуск (критично)
1. [ ] Открыть сайт в Safari при включённом интернете.
2. [ ] «Поделиться» → «На экран «Домой»».
3. [ ] **Запустить установленное приложение с интернетом**, дождаться уведомления «…будет работать без интернета».
4. [ ] Настройки → «Диагностика»: «Офлайн-запуск готов», «Управляет страницей: да», «Оболочка (/) в precache: да».
5. [ ] Создать тетрадь, написать несколько строк, в верхней панели появилось «Сохранено».
6. [ ] Полностью закрыть приложение (свайп вверх в переключателе приложений).
7. [ ] Включить авиарежим.
8. [ ] Запустить приложение с экрана «Домой»: открывается библиотека.
9. [ ] Открыть тетрадь и продолжить писать.
10. [ ] Ещё раз закрыть и открыть приложение без интернета: все строки на месте.
11. [ ] Открыть ранее импортированный PDF в авиарежиме.
12. [ ] Включить интернет, опубликовать новую версию, вернуться в приложение: баннер «Доступна новая версия».
13. [ ] Нажать «Обновить» во время письма: штрих не прерывается, после перезапуска заметки на месте, версия в настройках новая.

## 1а. Прокрутка и масштаб (обновление 3.0)
1. [ ] Открыть тетрадь из 30 страниц (добавить страницы кнопкой «+»).
2. [ ] Десять свайпов пальцем вниз подряд: каждый двигает документ, нет рывков в начало или конец.
3. [ ] Десять свайпов вверх.
4. [ ] Остановиться в середине, ещё несколько свайпов.
5. [ ] Увеличить щипком до ~200% и повторить прокрутку; точка между пальцами остаётся под пальцами.
6. [ ] Уменьшить до 50% и до 400% (индикатор масштаба внизу справа), «100%» и «По ширине» работают.
7. [ ] Написать пером несколько слов после масштабирования: линия точно под кончиком пера.
8. [ ] Сразу после письма снова прокрутить пальцем: работает.
9. [ ] Повернуть iPad: остаётся видна та же часть страницы.
10. [ ] Ластик и PDF после масштабирования работают.

## 1б. Давление
1. [ ] Настройки → «Диагностика Apple Pencil»: провести слабо и сильно — минимум и максимум давления различаются, сообщение «Датчик давления работает».
2. [ ] Ручка «Перьевая»: слабое нажатие — тонкая линия, сильное — толстая, переход плавный.
3. [ ] Пресеты «Мягкая» / «Средняя» / «Сильная» заметно различаются; «Чувствительность к нажатию» выключена — ровная линия.
4. [ ] Каллиграфия «По нажатию» и «По направлению»; после повторного открытия тетради штрихи выглядят так же.
5. [ ] На устройстве без датчика (Pencil USB-C, палец) диагностика честно сообщает об имитации.

## 1в. Стартовая анимация
1. [ ] Семь полных перезапусков приложения (закрыть свайпом и открыть): каждый раз новый язык из семи, без повторов.
2. [ ] Надпись пишется плавно, без ломаных линий и рывков, примерно за 3 с; утолщения нарастают постепенно; между словами короткие паузы; затем пауза, сердечко, короткая готовая композиция и плавный переход в библиотеку.
3. [ ] Кнопки «Пропустить» нет; композиция по центру экрана в portrait и landscape, на iPhone помещается целиком.
4. [ ] Настройки → «Анимация при запуске» выключена: библиотека открывается сразу.
5. [ ] В авиарежиме анимация и запуск работают.
6. [ ] Универсальный доступ → Движение → «Уменьшение движения»: готовая надпись показывается ~1,5 с без анимации.

## 1г. Cozy & Love (обновление 4.3)
1. [ ] Ещё → «Шаблон и бумага» → Cute Paper: каждый из 10 шаблонов применяется к текущей странице и ко всем страницам; размер клетки/шаг линий, цвет линий и «Декоративные детали» меняются; при зуме 400% линии чёткие; после перезапуска сохраняется; в экспортированном PDF бумага та же.
2. [ ] Кнопка «Стикеры» на панели: категории, поиск, ☆ избранное, «Недавние». Стикер появляется выделенным; перемещение, угловые ручки (размер), верхняя точка (поворот), отражение, прозрачность, дублирование, «на передний/задний план», удаление, отмена/повтор. После закрытия и открытия тетради стикеры редактируются; в PDF есть.
3. [ ] «Мои» → «+»: PNG, WebP и SVG из «Файлов» добавляются; удаление из библиотеки не стирает уже вставленные.
4. [ ] Во время письма Apple Pencil с открытой и закрытой панелью стикеров задержка не изменилась (панель производительности: frame < 8 мс).
5. [ ] Библиотека → «…» у тетради → «Обложка…»: коллекции, название, шрифт, размер/цвет/положение текста, фон, узор, украшения, фото (масштаб, перетаскивание пальцем по превью). Сохранить → обложка в библиотеке; после перезапуска на месте; страницы не изменились.
6. [ ] Настройки → «О приложении» → 5 быстрых нажатий на сердечко рядом с «Pencil Notes»: надпись «Сделано с любовью. Специально для тебя ♡» пишется пером, затем строка «В каждой строчке — немного моей любви»; остаётся до закрытия крестиком. 4 нажатия ничего не открывают. Работает в авиарежиме.
7. [ ] Heart Moment (нужно ~35–60 минут реальной учёбы): маленькое сердечко с фразой появляется слева внизу только в паузе, не во время письма, щипка, выделения, открытых окон, импорта/экспорта; не мешает касаниям; исчезает само через ~8 с. Время в фоне и при заблокированном экране не считается.

## 2. Письмо и стабилизация
- [ ] Медленные и быстрые линии, мелкие и крупные буквы, петли, острые углы, быстрые росчерки: без дрожания, без «угловатости», без пропусков.
- [ ] Стабилизация «Выкл.» / «Слабая» / «Средняя» / «Сильная»: разница заметна, при «Сильной» линия слегка отстаёт от пера при медленном письме (это ожидаемо).
- [ ] При отпускании пера линия не меняется скачком и на конце нет крючка.
- [ ] Давление: лёгкое и сильное нажатие дают разную толщину (Pencil 1/2/Pro). Для Pencil USB-C толщина зависит от скорости или направления (Настройки → площадка проверки показывает «давление не меняется»).
- [ ] Удержание пера в конце линии: линия выпрямляется.

## 3. Типы пера
- [ ] Каллиграфия: нисходящие линии толстые при нажиме, восходящие волосяные, концы сужаются, на поворотах нет артефактов; после повторного открытия и в экспортированном PDF выглядит так же.
- [ ] Шариковая, перьевая, кисть, линер, карандаш (зерно), маркер (прозрачность), монолиния — видимые отличия.
- [ ] Пресеты «Быстрые заметки», «Аккуратный почерк», «Каллиграфия», «Рисование».
- [ ] Настройки каждого типа пера запоминаются при переключении.

## 4. Ластик
- [ ] Курсор ластика движется плавно и без задержки даже на странице с большим количеством записей.
- [ ] «Точный» стирает только участок; «Штрих» удаляет линию целиком; «Объект» удаляет фигуры, текст и изображения.
- [ ] Одно «Отменить» отменяет весь проход ластика.

## 5. Фигуры
- [ ] После рисования фигура сразу выделена: рамка, 8 ручек, ручка поворота, панель «Стиль».
- [ ] Изменение ширины и высоты отдельно, Shift (клавиатура) сохраняет пропорции; поворот; перемещение.
- [ ] Обводка, заливка, «без заливки», толщина, прозрачность, скругление; на передний и задний план; дублирование; удаление.
- [ ] Касание фигуры инструментом «Фигуры» или «Лассо» снова открывает редактирование.
- [ ] При сильном увеличении ручки остаются удобного размера.
- [ ] «Авто»: нарисованный от руки круг или прямоугольник становится редактируемой фигурой.

## 6. Перелистывание и большие документы
- [ ] Тетрадь из 100+ страниц и большой PDF: быстрая прокрутка без длительных пустых страниц и зависаний.
- [ ] Миниатюры появляются, не тормозя прокрутку.
- [ ] Приложение не падает при долгой работе с большим PDF (память).

## 7. Касания и жесты
- [ ] «Только стилус»: палец не рисует, одним пальцем прокрутка, двумя масштаб.
- [ ] Ладонь во время письма не оставляет следов и не сдвигает страницу.
- [ ] Касание двумя пальцами — отменить, тремя — повторить.
- [ ] Нет лупы, выделения текста и контекстного меню при удержании пера.

## 8. Темы
- [ ] Системная, Розовая, Светлая, Тёмная, Тёплая бумага, Графит переключаются мгновенно.
- [ ] После перезапуска нет «мигания» другой темы.
- [ ] Бумага и PDF в тёмной теме не перекрашиваются.

## 9. Импорт
- [ ] Выбрать сразу несколько PDF и изображений: очередь, прогресс, все тетради в библиотеке.
- [ ] ZIP с папками (экспорт Goodnotes в PDF): структура папок восстановлена, русские названия корректны.
- [ ] Повторный импорт того же ZIP: документы помечены «Уже есть в библиотеке».
- [ ] Отмена во время импорта.
- [ ] Файл `.goodnotes`: понятное сообщение с рекомендацией экспортировать в PDF.

## 10. Данные
- [ ] Резервная копия библиотеки, восстановление в режиме «Добавить».
- [ ] iPhone: панель инструментов внизу, вырез экрана и Home indicator ничего не перекрывают.
