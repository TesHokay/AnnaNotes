## Проверки

- `npm run typecheck` — без ошибок.
- `npm test` — 103 теста в 17 файлах проходят (в т.ч. стабилизация, модели ширины, ластик и индекс, фигуры, темы, ZIP-импорт, миграция IndexedDB, стресс-тесты).
- `npm run test:e2e` (Chromium, сервер с поведением Cloudflare) — все 7 сценариев проходят (запускались по файлам, не одним прогоном): офлайн после первого визита; холодный старт без сети (`/`, `/index.html`, диагностика); создание → рисование → перезагрузка; undo/redo и страницы; ластик и лассо; библиотека (переименование, корзина, восстановление); импорт PDF → маркер → экспорт PDF. Один полный прогон до исправления хелперов однажды завис на тесте библиотеки (зависание окружения, отдельно тест проходит).
- `npm run build` — успешно.

## Что нужно сделать владельцу

1. **GitHub:** создать пустой репозиторий и выполнить `git remote add origin …` и `git push -u origin main` (README → «Шаг 1»). В проекте нет `gh` CLI и учётных данных GitHub, поэтому отправить код автоматически нельзя.
2. **Cloudflare автодеплой:** Workers & Pages → `annanotes` → Settings → Build → Connect (README → «Шаг 2»). Build: `npm run build`, deploy: `npx wrangler deploy`.
3. **iPad:** пройти [IPAD_TEST_CHECKLIST.md](IPAD_TEST_CHECKLIST.md), особенно раздел 1 (офлайн) — установленное приложение нужно один раз открыть с интернетом.

## Открытые задачи

1. Замеры FPS и задержки пера на физическом iPad (панель производительности).
2. Наклон пера (`tiltX/tiltY`) сохраняется, но не влияет на форму штриха (можно использовать для карандаша и кисти).
3. Генерация миниатюр и PDF-растров в Worker/OffscreenCanvas: pdf.js уже рендерит в своём worker, но растеризация штрихов идёт в основном потоке (только в простое).
4. Многоугольник рисуется правильным шестиугольником; редактирование отдельных вершин не реализовано.
5. Перенос выделения между страницами (сейчас через «Вырезать/Вставить»).
6. Подготовка к синхронизации: журнал изменений, ревизии элементов.
7. Уязвимости только в dev-зависимостях (vitest/tinypool): обновить vitest до 4.x.
8. Проект Playwright WebKit (эмуляция iPad) не запускался: на Windows WebKit не поддерживает Service Worker.
