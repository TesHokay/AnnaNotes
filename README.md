# AnnaNotes

PWA для рукописных заметок и пометок в PDF на iPad и iPhone (также работает на компьютере). Все документы хранятся только на устройстве (IndexedDB), приложение запускается и работает без интернета.

**Возможности:** библиотека с вложенными папками, избранным, корзиной, поиском и сортировкой · тетради A4/A5/Letter, книжная и альбомная ориентация, шаблоны (пустой лист, линейка, клетка, точки), свой цвет бумаги · ручка трёх типов с учётом нажатия, маркер, ластик (весь штрих или его часть), лассо (перемещение, масштаб, поворот, цвет, копирование), фигуры с автораспознаванием, текст, изображения · импорт PDF, рисование и маркер поверх PDF, экспорт в PDF и PNG · резервные копии одной тетради или всей библиотеки.

## Быстрый старт (локально)

Нужен Node.js 20 или новее.

```bash
npm install          # postinstall копирует CMap-файлы и шрифты pdf.js в public/pdfjs
npm run dev          # http://localhost:5173 — dev-сервер, без service worker
```

Проверки:

```bash
npm run typecheck    # TypeScript strict
npm test             # юнит- и интеграционные тесты (Vitest)
npm run build        # production-сборка в dist/
npm run preview      # раздаёт dist/ на http://127.0.0.1:4173 (с service worker)
npx playwright install chromium webkit   # один раз
npm run test:e2e     # E2E-тесты (Playwright), сами собирают и запускают preview
```

### Как проверить на iPad до деплоя

Service worker (офлайн-режим и установка) работает только по **HTTPS** или на `localhost`. Поэтому:

- **Полная проверка (офлайн, установка на экран «Домой»)** — задеплойте проект на Cloudflare Pages (см. ниже) и откройте выданный адрес `https://….pages.dev` в Safari на iPad.
- **Быстрая проверка рисования по Wi-Fi** — запустите `npm run dev -- --host` и откройте на iPad адрес вида `http://192.168.x.x:5173`. Рисование, хранение и PDF работают, а офлайн-режим и установка — нет (страница открыта не по HTTPS).

## Деплой на Cloudflare Pages

Приложение — полностью статический сайт: сервер, база данных и переменные окружения не нужны.

### Вариант А. Через GitHub (рекомендуется, автодеплой при каждом push)

1. **Создайте репозиторий на GitHub** (например, `pencil-notes`), можно приватный.
2. **Отправьте в него код** из папки проекта:
   ```bash
   git add .
   git commit -m "AnnaNotes"
   git remote add origin https://github.com/<ваш-логин>/pencil-notes.git
   git push -u origin main
   ```
3. Войдите в [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages** → **Create** → вкладка **Pages** → **Connect to Git**.
4. Разрешите Cloudflare доступ к GitHub и выберите репозиторий.
5. Настройки сборки:

   | Поле | Значение |
   |---|---|
   | Framework preset | `Vite` (или `None`) |
   | Build command | `npm run build` |
   | Build output directory | `dist` |
   | Root directory | *(оставить пустым)* |
   | Environment variable | `NODE_VERSION` = `20` (или новее) |

6. Нажмите **Save and Deploy**. Через 1–2 минуты сайт будет доступен по адресу `https://<проект>.pages.dev`.
7. Дальше каждый `git push` в `main` автоматически пересобирает сайт, а ветки и pull request'ы получают отдельные preview-адреса.

### Вариант Б. Без GitHub, из командной строки (Wrangler)

```bash
npm run build
npx wrangler login                 # откроет браузер для входа в Cloudflare
npx wrangler pages deploy dist --project-name pencil-notes
```

При первом запуске Wrangler предложит создать проект. Чтобы обновить сайт, повторите `npm run build` и `npx wrangler pages deploy dist`.

### Свой домен (необязательно)

Pages → ваш проект → **Custom domains** → **Set up a domain**. HTTPS-сертификат Cloudflare выпустит автоматически.

### Заголовки кэширования

Файл [public/_headers](public/_headers) попадает в `dist/` и задаёт правила для Cloudflare: `sw.js`, `index.html` и манифест не кэшируются браузером (иначе пользователи долго не получат обновление), а файлы из `/assets/` с хешем в имени кэшируются навсегда.

### Установка на iPad

1. Откройте адрес сайта в **Safari** (установка из Chrome на iPadOS не поддерживается).
2. Дождитесь уведомления «Приложение сохранено на устройстве и будет работать без интернета».
3. Нажмите **Поделиться** → **На экран «Домой»**.
4. Проверка: включите авиарежим и запустите приложение с экрана «Домой» — оно должно открыться вместе со всеми документами.

### Обновление приложения

После нового деплоя установленное приложение покажет баннер «Доступна новая версия». Обновление применяется только по нажатию кнопки: приложение ждёт окончания текущего штриха и записи всех изменений, затем перезагружается. Документы хранятся отдельно от кэша приложения и при обновлении не затрагиваются.

## Данные и резервные копии

- Документы хранятся в IndexedDB этого браузера на этом устройстве. Синхронизации между устройствами пока нет.
- Если очистить данные сайта в Safari или удалить приложение с экрана «Домой», документы будут удалены. Safari может удалить данные сайта, который не открывали 7 дней, — на установленные на экран «Домой» приложения это правило не распространяется.
- **Регулярно делайте резервные копии:** Настройки → «Копия всей библиотеки». Получится файл `.annanotes` (zip-архив). Восстановление: Настройки → «Восстановить из копии». По умолчанию документы из копии добавляются рядом с существующими; замена всей библиотеки требует отдельного подтверждения.

## Архитектура

```
src/
  model/        типы документа (страницы, штрихи, текст, изображения), форматы бумаги
  engine/       Drawing Engine — без React: ввод (Pointer Events), жесты, вьюпорт,
                сглаживание, давление, контуры штрихов, ластик, фигуры, лассо, история,
                рендеринг Canvas 2D с кэшем страниц и частичной перерисовкой
  db/           Dexie: схема с версиями и миграциями, репозиторий, очередь автосохранения
  pdf/          pdf.js (отображение, текстовый слой), импорт и экспорт через pdf-lib,
                преобразование координат с учётом /Rotate и CropBox
  backup/       версионированный формат резервной копии, проверка структуры, восстановление
  export/       растеризация страниц (PNG, миниатюры)
  editor/       сессия открытого документа (модель + кэши + операции со страницами)
  features/     React-интерфейс: библиотека, редактор, настройки
  store/        Zustand: настройки, интерфейс, состояние редактора
```

React отвечает только за интерфейс. Движок получает инструменты через подписки на стор и сообщает о событиях колбэками с низкой частотой — на каждое движение пера React не перерисовывается. Подробности и известные ограничения — в [docs/LIMITATIONS.md](docs/LIMITATIONS.md), сценарии ручной проверки на iPad — в [docs/MANUAL_TEST_CHECKLIST.md](docs/MANUAL_TEST_CHECKLIST.md), статус работ — в [PROGRESS.md](PROGRESS.md).

## Горячие клавиши (компьютер, клавиатура для iPad)

`P` ручка · `H` маркер · `E` ластик · `L` лассо · `S` фигуры · `T` текст · `Ctrl/⌘+Z` отменить · `Ctrl/⌘+Shift+Z` или `Ctrl+Y` повторить · `Ctrl/⌘+C/X/V` копировать / вырезать / вставить · `Ctrl/⌘+A` выделить всё на странице · `Ctrl/⌘+D` дублировать · `Delete` удалить выделенное · `Ctrl/⌘ +/−/0` масштаб · `Пробел` + перетаскивание — прокрутка · `PageUp/PageDown` · `Shift+P` панель производительности.

Жесты: два пальца — масштаб и прокрутка, касание двумя пальцами — отменить, тремя — повторить; удержание пера в конце линии выпрямляет её или распознаёт фигуру.
