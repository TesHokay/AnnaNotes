# AnnaNotes

PWA для рукописных заметок и пометок в PDF на iPad и iPhone (также работает на компьютере). Все документы хранятся только на устройстве (IndexedDB), приложение запускается и работает без интернета.

**Возможности:** 8 типов пера (включая каллиграфическое острое перо) со стабилизацией почерка · редактируемые векторные фигуры · массовый импорт PDF/ZIP (в том числе экспорт из Goodnotes) · 6 тем оформления · библиотека с вложенными папками, избранным, корзиной, поиском и сортировкой · тетради A4/A5/Letter, книжная и альбомная ориентация, шаблоны (пустой лист, линейка, клетка, точки), свой цвет бумаги · ручка трёх типов с учётом нажатия, маркер, ластик (весь штрих или его часть), лассо (перемещение, масштаб, поворот, цвет, копирование), фигуры с автораспознаванием, текст, изображения · импорт PDF, рисование и маркер поверх PDF, экспорт в PDF и PNG · резервные копии одной тетради или всей библиотеки.

## Быстрый старт (локально)

Нужен Node.js 20 или новее.

```bash
npm install          # postinstall копирует CMap-файлы и шрифты pdf.js в public/pdfjs
npm run dev          # http://localhost:5173 — dev-сервер, без service worker
```

Проверки:

```bash
npm run typecheck    # TypeScript strict
npm test             # юнит- и интеграционные тесты (Vitest)
npm run build        # production-сборка в dist/
npm run preview      # раздаёт dist/ на http://127.0.0.1:4173 (с service worker)
node scripts/serve-like-cloudflare.mjs   # dist/ с поведением Cloudflare (редиректы .html, SPA)
npx playwright install chromium webkit   # один раз
npm run test:e2e     # E2E-тесты (Playwright), сами собирают и запускают preview
```

### Как проверить на iPad до деплоя

Service worker (офлайн-режим и установка) работает только по **HTTPS** или на `localhost`. Поэтому:

- **Полная проверка (офлайн, установка на экран «Домой»)** — опубликуйте проект на Cloudflare (см. ниже) и откройте выданный адрес `https://….pages.dev` в Safari на iPad.
- **Быстрая проверка рисования по Wi-Fi** — запустите `npm run dev -- --host` и откройте на iPad адрес вида `http://192.168.x.x:5173`. Рисование, хранение и PDF работают, а офлайн-режим и установка — нет (страница открыта не по HTTPS).

## Публикация (Cloudflare) и автодеплой из GitHub

Приложение — статический сайт: сервер, база данных и переменные окружения не нужны. Сейчас оно опубликовано как **Cloudflare Worker со статическими файлами**: `https://annanotes.teshokay28.workers.dev`. Конфигурация лежит в [wrangler.jsonc](wrangler.jsonc).

### Шаг 1. Отправить код в GitHub (один раз)

1. На [github.com/new](https://github.com/new) создайте пустой репозиторий `annanotes` (можно приватный; без README и .gitignore).
2. В PowerShell в папке проекта:
   ```powershell
   git remote add origin https://github.com/<ваш-логин>/annanotes.git
   git push -u origin main
   ```
   При первом `push` Git Credential Manager откроет браузер для входа в GitHub.

### Шаг 2. Включить автодеплой в Cloudflare (один раз)

**Вариант А — существующий Worker `annanotes` (адрес `*.workers.dev` останется прежним):**

1. [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages** → `annanotes` → **Settings** → **Build** → **Connect** (Git repository).
2. Выберите GitHub и репозиторий `annanotes`.
3. Настройки сборки:

   | Поле | Значение |
   |---|---|
   | Production branch | `main` |
   | Build command | `npm run build` |
   | Deploy command | `npx wrangler deploy` |
   | Root directory | *(пусто)* |

4. Сохраните. Каждый `git push` в `main` запускает сборку и публикацию. Статус — во вкладке **Deployments**; там же виден commit, из которого сделан деплой.

**Вариант Б — Cloudflare Pages (адрес `*.pages.dev`):** Workers & Pages → **Create** → **Pages** → **Connect to Git** → репозиторий. Build command `npm run build`, output directory `dist`, переменная `NODE_VERSION` = `20`.

GitHub Actions для деплоя не нужен — сборку выполняет сам Cloudflare.

### Ручная публикация (без GitHub)

```powershell
npm run build
npx wrangler login     # один раз; не закрывайте терминал, пока браузер не покажет «Successfully logged in»
npx wrangler deploy    # Worker из wrangler.jsonc; для Pages: npx wrangler pages deploy dist --project-name annanotes
```

### Как убедиться, что опубликована нужная версия

- Настройки → «Для разработчиков»: версия, commit и статус офлайн-кэша запущенного приложения.
- Настройки → «Диагностика PWA и хранилища» (`#/diagnostics`): версия запущенной сборки рядом с опубликованной (`/version.json`), состояние Service Worker и precache, кнопка «Проверить обновление».
- В Cloudflare → Deployments: commit SHA, из которого собран деплой.

### Заголовки кэширования

[public/_headers](public/_headers) запрещает браузеру кэшировать `sw.js`, `index.html` и манифест (иначе обновления приходят с большой задержкой), а файлы `/assets/*` с хешем в имени кэшируются навсегда.

### Установка на iPad и работа без интернета

1. Откройте адрес в **Safari** (из Chrome на iPadOS установка не поддерживается).
2. «Поделиться» → **«На экран «Домой»»**.
3. **Запустите установленное приложение с экрана «Домой» один раз при включённом интернете** и дождитесь сообщения «Приложение сохранено на устройстве и будет работать без интернета». На iPadOS установленное приложение хранит кэш и данные **отдельно от Safari** — подготовка во вкладке Safari его не касается.
4. Проверка: Настройки → «Диагностика» → «Офлайн-запуск готов». Затем включите авиарежим, полностью закройте приложение и откройте снова.

Заметки, созданные во вкладке Safari, не видны в установленном приложении (это разные хранилища). Чтобы перенести их, сделайте резервную копию в Safari и восстановите её в приложении.

### Обновление приложения

После нового деплоя приложение находит обновление при возвращении на экран, при появлении сети и раз в час. Появляется баннер «Доступна новая версия». Обновление применяется только по нажатию: приложение ждёт окончания текущего штриха и записи изменений, затем перезагружается. Заметки хранятся в IndexedDB отдельно от кэша приложения и при обновлении не удаляются.

## Данные и резервные копии

- Документы хранятся в IndexedDB этого браузера на этом устройстве. Синхронизации между устройствами пока нет.
- Если очистить данные сайта в Safari или удалить приложение с экрана «Домой», документы будут удалены. Safari может удалить данные сайта, который не открывали 7 дней, — на установленные на экран «Домой» приложения это правило не распространяется.
- **Регулярно делайте резервные копии:** Настройки → «Копия всей библиотеки». Получится файл `.annanotes` (zip-архив). Восстановление: Настройки → «Восстановить из копии». По умолчанию документы из копии добавляются рядом с существующими; замена всей библиотеки требует отдельного подтверждения.

## Архитектура

```
src/
  model/        типы документа (страницы, штрихи, текст, изображения), форматы бумаги
  engine/       Drawing Engine — без React: ввод (Pointer Events), жесты, вьюпорт,
                сглаживание, давление, контуры штрихов, ластик, фигуры, лассо, история,
                рендеринг Canvas 2D с кэшем страниц и частичной перерисовкой
  db/           Dexie: схема с версиями и миграциями, репозиторий, очередь автосохранения
  pdf/          pdf.js (отображение, текстовый слой), импорт и экспорт через pdf-lib,
                преобразование координат с учётом /Rotate и CropBox
  backup/       версионированный формат резервной копии, проверка структуры, восстановление
  export/       растеризация страниц (PNG, миниатюры)
  editor/       сессия открытого документа (модель + кэши + операции со страницами)
  features/     React-интерфейс: библиотека, редактор, настройки
  store/        Zustand: настройки, интерфейс, состояние редактора
```

React отвечает только за интерфейс. Движок получает инструменты через подписки на стор и сообщает о событиях колбэками с низкой частотой — на каждое движение пера React не перерисовывается. Подробности и известные ограничения — в [docs/LIMITATIONS.md](docs/LIMITATIONS.md), сценарии ручной проверки на iPad — в [IPAD_TEST_CHECKLIST.md](IPAD_TEST_CHECKLIST.md), статус работ — в [PROGRESS.md](PROGRESS.md).

## Горячие клавиши (компьютер, клавиатура для iPad)

`P` ручка · `H` маркер · `E` ластик · `L` лассо · `S` фигуры · `T` текст · `Ctrl/⌘+Z` отменить · `Ctrl/⌘+Shift+Z` или `Ctrl+Y` повторить · `Ctrl/⌘+C/X/V` копировать / вырезать / вставить · `Ctrl/⌘+A` выделить всё на странице · `Ctrl/⌘+D` дублировать · `Delete` удалить выделенное · `Ctrl/⌘ +/−/0` масштаб · `Пробел` + перетаскивание — прокрутка · `PageUp/PageDown` · `Shift+P` панель производительности.

Жесты: два пальца — масштаб и прокрутка, касание двумя пальцами — отменить, тремя — повторить; удержание пера в конце линии выпрямляет её или распознаёт фигуру.
