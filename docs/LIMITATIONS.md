# Известные ограничения: Safari, iPadOS и Apple Pencil

## Apple Pencil в браузере

| Возможность | Статус | Подробности |
|---|---|---|
| Распознавание пера | ✅ | `pointerType === 'pen'`, перо отделяется от касаний пальцами |
| Давление | ✅ при наличии датчика | Используется `event.pressure`. Приложение проверяет, меняется ли давление во время штриха. Если нет (мышь, палец, Apple Pencil USB-C без датчика давления), толщина линии зависит от скорости. Проверить своё устройство можно в Настройках → «Проведите здесь пером» |
| Каллиграфия без датчика давления | ⚠️ имитация | Если перо не передаёт давление, контраст каллиграфической ручки строится только по направлению движения (нисходящие линии толще). Это явная имитация, а не измеренное давление |
| Наклон | ⚠️ сохраняется, не влияет на штрих | `tiltX/tiltY` записываются в каждую точку, но пока не используются при отрисовке |
| Coalesced / predicted events | ⚠️ при поддержке | `getCoalescedEvents` и `getPredictedEvents` используются, только если браузер их предоставляет; наличие видно на панели производительности |
| Наведение пера (hover) | ⚠️ частично | На iPad с поддержкой hover Safari присылает `pointermove` без нажатия — ластик показывает курсор |
| Двойное касание (Pencil 2), сжатие (Pencil Pro), поворот пера | ❌ | Веб-API не предоставляют эти события, приложение их не имитирует |
| Scribble (рукописный ввод в поля) | — | Работает системно в текстовых полях; на холсте отключён |

## Офлайн и хранение

- **Установленное на экран «Домой» приложение на iPadOS хранит Service Worker, кэш и IndexedDB отдельно от Safari.** После установки его нужно один раз запустить с интернетом, иначе без сети оно не откроется. Заметки, созданные во вкладке Safari, в установленном приложении не видны: перенесите их через резервную копию.
- Service worker работает только по HTTPS (или на localhost).
- В приватном режиме Safari IndexedDB может быть недоступна или ограничена — приложение показывает ошибку хранилища.
- Safari может удалить данные сайта, который не открывали 7 дней. На установленные на экран «Домой» приложения это не распространяется. Запрос `navigator.storage.persist()` — в Настройках («Защитить»).
- Квота хранилища зависит от свободного места на устройстве. При переполнении приложение показывает баннер, сохраняет изменения в памяти и повторяет запись; несохранённые данные теряются, если в этот момент закрыть приложение.
- `beforeunload` на iOS ненадёжен, поэтому сохранение идёт сразу после каждого завершённого действия (с задержкой ~350 мс) и принудительно на `visibilitychange`/`pagehide`. Штрих, который ещё рисуется, при принудительном завершении приложения теряется.

## PDF

- Текст в экспортированном PDF вставляется картинкой (стандартные шрифты PDF не поддерживают кириллицу) и не выделяется. Штрихи, фигуры и маркер экспортируются как векторы.
- Текстура карандаша растровая: в PDF карандаш экспортируется ровной линией с прозрачностью 80%.
- Перекрывающиеся штрихи маркера в экспортированном PDF чуть темнее в местах пересечения (на экране прозрачность одинаковая).
- PDF, защищённые паролем на открытие, не поддерживаются.
- Аннотации привязаны к страницам и хранятся отдельно от исходного PDF; исходный файл не изменяется.
- Максимальный размер импорта: PDF — 200 МБ, изображение — 40 МБ (большие изображения уменьшаются до 3072 px по длинной стороне), резервная копия — 1 ГБ.

## Импорт из Goodnotes

- Нативный формат `.goodnotes` не документирован, поэтому рукописные слои и редактируемые объекты из него не извлекаются. Если в архиве есть вложенные исходные PDF или изображения, импортируются только они, и приложение об этом сообщает.
- Полный перенос: экспортируйте тетради или папки из Goodnotes в PDF и импортируйте PDF-файлы или ZIP-архив с ними. Структура папок восстанавливается; рукописные записи станут частью содержимого страниц (поверх можно писать, но старые штрихи не редактируются).

## Редактор

- Выделение лассо работает в пределах одной страницы; перенести объекты на другую страницу можно через «Вырезать» → «Вставить».
- Буфер обмена внутренний: копирование между AnnaNotes и другими приложениями не поддерживается.
- Очень большие страницы при сильном увеличении рендерятся по видимой области (ограничение памяти canvas в Safari) — при быстрой прокрутке края подгружаются с небольшой задержкой.
- Резервная копия собирается целиком в памяти: для библиотек размером в сотни мегабайт на старых iPad может не хватить памяти.
