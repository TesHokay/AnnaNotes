# Ручная проверка на iPad + Apple Pencil

Автотесты в настольном браузере не заменяют проверку на устройстве. Проверяйте на сборке, задеплоенной по HTTPS, в Safari и в установленном PWA.

Устройство / iPadOS / модель Pencil: ____________________

## Установка и офлайн
- [ ] Safari: открыть сайт, дождаться уведомления «будет работать без интернета»
- [ ] «На экран «Домой»»: иконка и название AnnaNotes, запуск без адресной строки
- [ ] Авиарежим → запуск с экрана «Домой» → библиотека и документы открываются
- [ ] В авиарежиме создать тетрадь, порисовать, закрыть приложение свайпом, открыть снова — всё на месте
- [ ] В авиарежиме открыть ранее импортированный PDF
- [ ] Задеплоить новую версию → баннер «Доступна новая версия» → «Обновить» во время рисования не прерывает штрих; документы на месте

## Перо и касания
- [ ] Режим «только стилус»: палец не рисует, одним пальцем прокручивается, двумя — масштаб
- [ ] Ладонь на экране во время письма не оставляет следов и не прокручивает страницу
- [ ] «Рисовать пальцем» включено: палец рисует; второй палец сразу после первого переключает на масштаб без случайной линии
- [ ] Давление: лёгкое и сильное нажатие дают разную толщину (Pencil 1/2/Pro); для Pencil USB-C толщина зависит от скорости
- [ ] Быстрые штрихи и мелкий почерк без разрывов и «угловатости»; задержка линии за пером незаметна
- [ ] Удержание пера в конце линии — линия выпрямляется; круг или прямоугольник распознаётся
- [ ] Свайп от края или системный жест во время штриха (pointercancel) — штрих сохраняется, ввод не «залипает»
- [ ] Не появляются лупа, выделение текста или контекстное меню при долгом удержании пера
- [ ] Страница браузера не масштабируется щипком вне холста

## Переключение инструментов
- [ ] Ручка → ластик → ручка: без потери настроек
- [ ] Ластик «частично» разрезает штрих; «штрих целиком» удаляет его полностью
- [ ] Лассо: выделение, перемещение, масштаб за угол, поворот, смена цвета, дублирование, удаление
- [ ] Масштабирование и прокрутка двумя пальцами между штрихами — ни одного случайного штриха
- [ ] Касание двумя пальцами — отменить, тремя — повторить

## Документы
- [ ] Новая тетрадь с каждым шаблоном и форматом, альбомная ориентация
- [ ] Добавить, дублировать, удалить, перетащить страницу в панели миниатюр; закладки
- [ ] Текст: создать, изменить шрифт/размер/цвет/выравнивание, переместить лассо
- [ ] Вставить фото из «Фото»/«Файлов», изменить размер, повернуть
- [ ] Импорт PDF на 100+ страниц: быстрая прокрутка без падения приложения
- [ ] Маркер по тексту PDF ложится ровно на строки
- [ ] Экспорт PDF → открывается в «Файлах»/Books, пометки на месте, повёрнутые страницы правильные
- [ ] Экспорт PNG страницы, резервная копия тетради и библиотеки; восстановление в режиме «Добавить»

## Интерфейс
- [ ] Альбомная и книжная ориентация iPad, Split View / Slide Over
- [ ] iPhone: панель инструментов внизу, вырез экрана и Home indicator ничего не перекрывают
- [ ] Тёмная тема; бумага остаётся светлой
- [ ] Открыть настройки во время работы — после закрытия инструмент и масштаб не сбрасываются
